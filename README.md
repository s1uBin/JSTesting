# PD 免廣告領獎 (Loon)

目標:看 Puzzle & Dragons 的「看廣告領獎勵」時,不必真的看完廣告就能拿到獎勵。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `PD免廣告.plugin` | 主腳本:攔截遊戲 `api.php` 請求(自動捕獲樣本) |
| `PD_capture.js` | 攔截腳本:記錄 參數+key+回應 到 Loon 本地存儲 |
| `PD_claim.js` | 手動執行:破解 key 算法 + 重放領獎測試 + 通知結果 |
| `PD視頻替換.plugin` | 備用方案:把廣告視頻換成 10 秒樣本視頻 |
| `crack_key.py` | PC 端 key 破解工具(Python,需要更多樣本時用) |

## 安裝 (iPhone / Loon)

1. 把整個資料夾的內容傳到手機(AirDrop / iCloud / 微信檔案傳輸等)。
2. 每個檔案長按 → 用 Loon 打開(或 Loon → 文件 → 匯入):
   - `PD免廣告.plugin` → 會成為一個本地腳本,確認**已啟用**。
   - `PD_capture.js`、`PD_claim.js` → 匯入為本地腳本(在 Loon 的「腳本」清單裡)。
3. 確認 Loon 的 MITM 已開啟且證書已信任(腳本會自動加入 `padsv.gungho.jp`)。

> 注意:`PD免廣告.plugin` 裡的 `script-path=PD_capture.js` 是相對引用。
> 如果 Loon 無法解析,請把 `PD_capture.js` 傳到 GitHub/Gist,然後把 plugin
> 裡的兩行 `script-path=` 改成該網址。

## 使用流程(方案 A:重放領獎)

1. **正常看 1 次廣告**領獎勵(讓腳本自動捕獲完整樣本:pid/sid/rid/t/key)。
2. 回到 Loon → 腳本 → 點 **`PD_claim.js`** 執行。
3. 看通知結果:
   - `T0 原樣重放 res=0` ✅ → 伺服器不去重,之後每次執行都直接領(同一筆獎勵可能只能領幾次,之後需要再看一次真廣告刷新 rid)
   - `T1 新t重放 res=0` ✅ → 同上,且可反覆使用
   - `T2 隨機rid res=0` ✅ → 最佳:rid 不驗證,幾乎無限
   - 全部 ❌ → 伺服器有驗證,把通知內容 + Loon 日誌發給我,繼續破解
   - 通知副標題若顯示 `key算法: xxx/yyy` → key 已破解,`T3 完全自主` 會自動執行

> 每次執行 PD_claim.js 前,建議先在遊戲裡看 1 次真廣告,讓樣本是最新的。

## 備用方案(方案 B:視頻替換)

如果方案 A 全部失敗:
1. 啟用 `PD視頻替換.plugin`。
2. 正常點「看廣告」,廣告會變成一支 10 秒的短片,播完遊戲照常領獎。
3. 成功後可以停用主腳本,只留視頻替換。

## 風險聲明

- 反覆刷獎勵可能被 gungho 反作弊封號,請控制頻率(建議每天 ≤5 次)。
- 視頻替換屬於規避廣告,違反廣告平台條款,風險自行承擔。
- 所有請求都發往遊戲自己的伺服器,不經過第三方。

## PC 端破解工具

```
python crack_key.py
```
把 PD_claim.js 捕獲的樣本(JSON)匯入後,可在 PC 上跑更全面的 key 窮舉。
